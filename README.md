# FormDesk

FormDesk is a WordPress plugin for managing custom user-submitted forms through an advanced administration panel.

It provides a complete form management system where website users can submit their information through customizable forms, while administrators can review, manage, and track submissions directly from the WordPress dashboard.

## Features

- Custom user registration and submission management
- Admin dashboard for managing submitted forms
- Configurable fields and submission statuses
- Real-time notification system for new submissions
- Export submissions to Excel files
- Generate PDF reports from submitted data
- WooCommerce integration for order-based workflows
- Secure file upload handling
- Database management for notifications and records
- WordPress native architecture following plugin standards

## Requirements

- WordPress 6.0+
- PHP 7.4+
- WooCommerce

## Purpose

FormDesk is designed for businesses, organizations, and websites that need a flexible solution to collect, organize, and manage user information submitted through online forms without relying on external form management services.

The plugin provides a structured workflow for handling user requests, reviewing submissions, updating statuses, and exporting collected data for further processing.

# فرم‌دسک

FormDesk یک افزونه وردپرس برای مدیریت فرم‌های سفارشی ارسال‌شده توسط کاربران از طریق یک پنل مدیریت پیشرفته است.

این افزونه یک سیستم کامل مدیریت فرم ارائه می‌دهد که کاربران سایت می‌توانند اطلاعات خود را از طریق فرم‌های قابل تنظیم ارسال کنند و مدیران سایت نیز می‌توانند تمامی درخواست‌ها و اطلاعات ثبت‌شده را مستقیماً از پیشخوان وردپرس مشاهده، مدیریت و پیگیری کنند.

## امکانات

- مدیریت ارسال‌های کاربران و فرم‌های سفارشی
- پنل مدیریت اختصاصی در پیشخوان وردپرس
- امکان تعریف و مدیریت فیلدهای فرم
- مدیریت وضعیت‌های مختلف برای درخواست‌ها
- سیستم اعلان برای ارسال‌های جدید
- خروجی گرفتن از اطلاعات در قالب فایل Excel
- تولید گزارش‌های PDF از اطلاعات ثبت‌شده
- یکپارچه‌سازی با WooCommerce برای فرآیندهای مبتنی بر سفارش
- مدیریت امن آپلود فایل‌ها
- ذخیره‌سازی و مدیریت اطلاعات در پایگاه داده وردپرس
- ساختار استاندارد افزونه‌های وردپرس و معماری توسعه‌پذیر

## نیازمندی‌ها

- WordPress نسخه 6.0 یا بالاتر
- PHP نسخه 7.4 یا بالاتر
- WooCommerce

## هدف پروژه

FormDesk برای کسب‌وکارها، سازمان‌ها و وب‌سایت‌هایی طراحی شده است که نیاز دارند اطلاعات کاربران را از طریق فرم‌های آنلاین دریافت، دسته‌بندی و مدیریت کنند؛ بدون اینکه به سرویس‌های خارجی مدیریت فرم وابسته باشند.

این افزونه یک گردش کار ساختاریافته برای دریافت درخواست‌های کاربران، بررسی اطلاعات، تغییر وضعیت درخواست‌ها و تهیه خروجی‌های قابل استفاده برای پردازش‌های بعدی فراهم می‌کند.
